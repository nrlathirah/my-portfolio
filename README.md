# Nurul Athirah — Portfolio

**🔗 Live site: [nrlathirah-portfolio.netlify.app](https://nrlathirah-portfolio.netlify.app/)**

Personal portfolio website for Nurul Athirah Zaini, Software Developer.

## Features

- Responsive layout (desktop, tablet, mobile)
- Light/dark theme toggle with saved preference
- Scroll-triggered reveal animations, animated skill bars, and a typewriter hero effect
- Work experience, skills, and project sections built from scratch with vanilla HTML/CSS/JS

## Tech Stack

- HTML5
- CSS3 (custom properties, no framework)
- Vanilla JavaScript

## Running Locally

This is a static site with no build step. Clone the repo and open `index.html` in a browser, or serve it locally:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.
